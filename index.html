About Me

I’m a graphic designer interested in branding, digital experiences, and visual storytelling. A lot of my work is influenced by things I’m into like music, snowboarding, and digital culture.

I create work that feels intentional, expressive, and connected to real people. Whether I’m building a brand system, designing an interface, or working on motion, I want the final result to feel clean, memorable, and grounded in a strong idea.

I also built this portfolio myself using HTML and CSS in Visual Studio Code, then published it through GitHub Pages. Doing it this way gave me full control over the structure, layout, and how my work is presented.
